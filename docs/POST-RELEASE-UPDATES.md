# Post-release updates

Baseline: Sober Dailies 3.0.8 shipped August 19, 2026.

Use this list to accumulate changes on `main` for the next bundled OTA. Do not
publish an OTA for every item; publish immediately only for a true urgent bug.

## Waiting for the next bundled OTA

- The downloaded-update prompt now says “An update is ready” and uses the
  clearer action label “Apply.”
- Journey history now displays each day's saved completion count and actual
  historical denominator. This keeps old day cards (for example, `2 of 6`)
  consistent with Trends, whose average is the mean of non-zero daily
  completion percentages.
- Shared Journey entries (gratitude lists, journal entries, nightly reviews,
  and spot checks) now show the month and day without the year.
